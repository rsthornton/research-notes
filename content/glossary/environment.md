# Environment

Everything outside the [[glossary/system|system]] [[glossary/boundary|boundary]] — the sources providing inputs, the sinks receiving outputs, and the context in which the system operates.

## Components

- **Sources**: Where inputs originate
- **Sinks**: Where outputs go
- **Channels**: Pathways for flows between system and environment

## Key Insight

The environment is not passive backdrop — it co-constitutes the system. A system's identity is partly defined by what it exchanges with its environment.

## Related Concepts

- [[glossary/system|System]] — what the environment surrounds
- [[glossary/boundary|Boundary]] — the interface between system and environment
