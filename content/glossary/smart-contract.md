# Smart Contract

Autonomous [[glossary/subsystem|subsystems]] executing on blockchain infrastructure — code that runs when triggered, enforcing agreements without intermediaries.

Smart contracts are deterministic programs stored on-chain. Given the same [[glossary/state|state]] and inputs, they always produce the same outputs. They enable complex [[glossary/flow|flows]] (token swaps, lending, governance) to execute trustlessly according to programmed logic.

## Systems Connection

A smart contract is a [[glossary/component|component]] within the larger blockchain [[glossary/system|system]]. It has its own [[glossary/state|state]] (storage variables), [[glossary/interface|interfaces]] (function signatures), and [[glossary/function|function]] (what it does when called). Composable smart contracts form [[glossary/subsystem|subsystems]] — DeFi protocols built from interacting contracts.
