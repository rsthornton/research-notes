# Temporal Coding

Encoding information in the precise timing of spikes rather than firing rates — exploiting time as a computational dimension.

In temporal coding, when a neuron fires matters as much as whether it fires. Mechanisms include time-to-first-spike coding, phase coding relative to oscillations, and synchrony-based coding where simultaneous spikes from multiple neurons carry meaning.

## Systems Connection

Temporal coding treats time as part of the [[glossary/state|state]] representation. Information exists not just in which [[glossary/component|components]] are active but in the precise temporal relationships between their [[glossary/flow|flows]] (spikes). This enables [[glossary/emergence|emergent]] computational capabilities — the same components can represent different information through different timing patterns.
