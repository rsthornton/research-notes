# System

An organized set of interacting components forming a coherent whole, with identifiable boundaries separating it from its environment.

## Key Properties

- **Composition**: The set of components that make up the system
- **Structure**: The relationships and arrangements between components
- **Environment**: What lies outside the [[glossary/boundary|boundary]]
- **Mechanism**: The processes that produce system behavior

## Related Concepts

- [[glossary/boundary|Boundary]] — defines what's inside vs outside
- [[glossary/environment|Environment]] — the system's context
- [[glossary/emergence|Emergence]] — properties the whole has that parts lack
