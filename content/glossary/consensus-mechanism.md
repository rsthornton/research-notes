# Consensus Mechanism

The process by which distributed [[glossary/component|components]] agree on a single [[glossary/state|state]] — solving the fundamental problem of coordination without central authority.

In blockchain systems, consensus mechanisms determine how nodes reach agreement on valid transactions and block ordering. Examples include Proof of Work (computational puzzles), Proof of Stake (economic collateral), and Byzantine Fault Tolerant protocols (voting rounds).

## Systems Connection

Consensus is a [[glossary/feedback-loop|feedback]] process operating at the [[glossary/system|system]] level. Each node proposes and validates based on local information, yet the network [[glossary/emergence|emerges]] to a shared state. The mechanism defines the [[glossary/boundary|boundary]] of valid behavior — what counts as a legitimate state transition.
